# Code Availability Statement

The source code supporting the experimental evaluation is preserved in a private version-controlled repository for authentication and reproducibility tracking.

The code includes scripts for Alibaba Microservices Trace preprocessing, GMM–EM workload-regime feature handling, graph feature construction, RL-style autoscaling simulation, baseline/proposed comparison, ablation study, and generation of reported tables and figures.

Since the work is part of an ongoing research extension, the full code is not publicly released at this stage. It can be made available to the editor or reviewers upon reasonable request for verification purposes under controlled access.

Recommended manuscript text:
