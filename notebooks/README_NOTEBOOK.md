# Notebook Availability Note

The original experimental notebook is preserved in this folder for record and verification purposes.

If GitHub does not render the notebook preview in the browser, please download the `.ipynb` file and open it locally using Jupyter Notebook or JupyterLab.

The modular Python scripts available in the `src/` folder should be treated as the primary reproducibility files for verification. These scripts organize the workflow for dataset inventory, graph feature construction, baseline/proposed evaluation, ablation study, and manuscript figure generation.
